# 报销规则测试制度（Demo）

## 1. 通用审批规则

1. 报销单必须填写报销人、部门、费用类型、金额、费用日期和业务说明。
2. 报销金额必须小于或等于可用预算；审批后预算为负数的，不允许自动通过。
3. 报销单必须关联真实有效的发票。发票验真失败、疑似重复发票、缺少发票号码或缺少附件时，必须人工复核或退回补充。
4. 报销制度引用必须来自知识库规则。未找到规则引用时，智能审批只能给出审批意见，不允许自动通过。
5. 自动通过只适用于低风险单据。存在红色风险或黄色风险时，不得自动通过。

## 2. 差旅住宿费标准

1. 公司分管领导及各一级部门负责人：高消费城市住宿限额 800 元/间/夜，其他城市住宿限额 600 元/间/夜。
2. 其他员工：高消费城市住宿限额 600 元/间/夜，其他城市住宿限额 420 元/间/夜。
3. 同性别两人共同出差原则上入住一个标准间。住一个标准间住宿费不能超过 600 元/间/夜；因特殊原因各住一个标准间时，每间房价不应超过住宿标准额度的 70%。
4. 单次行程的交通费、住宿费和差旅补助原则上一次性报销，不得拆分补报。

## 3. 交通费规则

1. 市内交通费需说明出行事由、起止地点和对应项目。
2. 普通员工单次市内交通费标准上限为 200 元；超过 200 元的，系统标记黄色风险，需部门负责人说明。
3. 跨城市交通费需关联差旅申请单；未关联差旅申请单时，不允许自动通过。

## 4. 招待费规则

1. 招待费需填写客户名称、招待人数、招待事由和参与人员。
2. 一般商务招待标准不超过人均 150 元。超过标准的，系统标记黄色风险，需提交业务负责人审批。
3. 招待费缺少客户名称或招待人数时，系统标记红色风险，退回补充。

## 5. 办公费和采购费规则

1. 办公用品采购金额不超过 5000 元且发票、验收记录完整的，可进入低风险审批。
2. 采购费应关联采购订单和入库单。采购订单金额、入库金额、发票金额和报销金额应保持一致。
3. 金额不一致超过 100 元的，系统标记黄色风险，需采购和财务共同复核。
4. 未关联采购订单或入库单的采购费，不允许自动通过。

## 6. 低风险自动通过条件

开启自动通过开关时，只有同时满足以下条件才允许系统自动通过：

1. 知识库检索命中至少一条报销规则引用。
2. 审批风险等级为 LOW。
3. 风险项列表为空，不存在红色风险和黄色风险。
4. 发票验真通过，且不是重复发票。
5. 报销后预算不为负数。
6. 费用类型对应的必填单据完整，例如采购费需有采购订单和入库单，差旅费需有关联差旅申请或合理说明。

不满足以上任一条件时，系统只生成审批意见，状态保持 NEED_REVIEW、REJECTED 或 APPROVED_ROUTE_READY，不得直接写回 APPROVED。

## 7. 测试问答样例

1. 问：普通员工二线城市交通费 3200 元能自动通过吗？
   答：不能。普通员工单次市内交通费标准上限为 200 元，3200 元超标，应标记黄色风险并人工复核。
2. 问：采购费什么情况下可以低风险通过？
   答：办公或采购费用金额在标准内，发票验真通过，采购订单、入库单、发票金额和报销金额一致，预算充足，且知识库命中规则引用时，可以低风险通过。
3. 问：没有发票的报销单可以自动通过吗？
   答：不可以。缺少发票号码或附件属于红色风险，应退回补充。
